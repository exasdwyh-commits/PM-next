# 前端优化与联动缺陷检查 · 2026-10-02

本轮先处理 `/muse` 的会话体验，再扩展至产品、项目、设置和共享导航／弹窗，保留现有 Kern 视觉令牌和布局。接续工作区已有的会话重命名、归档功能，没有提交或覆盖其他在途改动。

## 已处理

- 输入框按内容增高，长文本可滚动；中文输入法确认候选时不会触发发送，Shift+Enter 保留换行。
- 会话切换分别保存草稿；发送失败恢复文本，迟到的发送结果不会追加到新选中的会话。
- 消息轮询检查实际内容，修复消息 ID 和数量不变时内容、来源更新无法显示的问题。隐藏页面暂停轮询，避免请求重叠。
- 运行配置保存和审批消息回执增加当前会话校验，避免切换后写入错误视图。
- 重命名使用站内表单，包含错误提示、初始焦点、Tab 焦点约束和 Escape 关闭；归档成功可撤销。
- 手机顶栏分行布局，320px 和 390px 下七个动作均可触达，按钮保留名称和至少 44px 的点击区域。
- 后端消息入口验证 JSON 对象及非空字符串；数字、对象、数组、null、空白消息返回 422，避免 `.trim()` 类型错误造成 500。校验在数据库和模型调用之前完成。
