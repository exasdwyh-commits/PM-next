# KX-61 连接器权限三档

## 目标
参考 Meta Muse 的做法：每个连接器可以整体设为“关闭 / 只读 / 读写交互”，不用逐个工具去点。

## 设计
- 不新增存储、不做数据库迁移。档位由已有的逐工具开关推出，切换档位就是批量改开关（`src/modules/connectors/policy.ts`）。
  - `off`：全部工具停用，Kern 不会用这个连接器。
  - `read`：读工具启用，写工具停用。
  - `interact`：全部启用；写工具映射 `external.send`，每次调用仍需审批凭据（KX-31 行为不变）。
  - `custom`：手动组合与三档都不一致时显示，下面仍可逐个工具设置。
- 刷新工具列表时保持档位：
  - 关闭的连接器，新出现的工具也保持关闭；
  - 读写交互下新出现的写工具默认停用，档位变为 `custom`，需要用户重新确认（与“读变写强制停用”同一原则）。
- 接口：复用 `PATCH /api/connectors/{id}`，新增请求体 `{ access: "off" | "read" | "interact" }`，非法值 422。返回的连接器视图新增 `access` 字段。
  - 没有新增路由或方法，authz 基线不因本项变化。
- 审计：`connector.access`，记录 from / to；切到读写交互时摘要注明写工具数量和“每次调用仍需确认”。
- 界面：连接器面板每个连接器标题下新增三段切换（关闭 / 只读 / 读写交互），旁边一句说明；逐工具开关保留。
