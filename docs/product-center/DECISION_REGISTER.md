## 2. 业务口径登记

> 每条口径必须带**出处**：计划章节号，或 `EXECUTION_STATUS.md` 的实测证据。出处不明者不登记。

### 2.1 成本

| 口径 | 出处 |
| --- | --- |
| 前端实时试算可保留；**保存时服务器用相同输入和固定引擎版本重新计算**，不接受客户端上传"最终利润" | 计划 §1.10 |
| 每项关键数值记 `KNOWN / ASSUMED / UNKNOWN` 和来源；`0` 只表示确认为零，null 表示未知 | 计划 §1.10 |
| 目标成本、估算成本、确认报价分别展示；含税/不含税、单件/每盒/每套、币种、佣金计费基数和退款处理不得混算 | 计划 §1.10 |
| 当前引擎 **L1–L5 汇总、L6 月固定成本单列**的口径先保持；改公式需另附对照样例与业务确认 | 计划 §1.10；契约 §3.2（既有） |
| 渠道费率、运费、税率、月固定成本预设均标"**待确认假设**"；页面默认月固定成本不得当真实公司数据 | 计划 §1.10 |
| 盈亏平衡在贡献不为正时显示"当前假设下无法达到"，不显示负件数或无穷大 | 计划 §1.10 |
| 保留兼容字段、**不擅改公式**；不称公司净利润或现行税务结论 | **DEC-009**（计划 §1.4） |

### 2.2 供应

| 口径 | 出处 |
| --- | --- |
| 报价和样品都先人工回传；外部原件与 AI 整理结果并存 | 计划 §1.10 |
| 比较仅在规格、数量、税费、运费、交期条件可比时成立；不同条件列差异，不只按最低单价排序 | 计划 §1.10 |
| **报价确认不等于采购下单** | 计划 §1.10 |
| 报价原件可定位且与生产版本一致 | 计划 §1.7（`SUPPLIER_QUOTE` 完成标准） |

### 2.3 营销

| 口径 | 出处 |
| --- | --- |
| 首版即写购买理由、差异、可信依据、价格机制和验证假设 | 计划 §1.10 |
| 生成素材必须绑定产品/品牌版本及表达依据；不能因为文案读起来合理就标"可发布" | 计划 §1.10 |
| "AI 生成素材" ≠ "已审核"；`producerType=AI` 不得 `reviewStatus=ACCEPTED` | 计划 §1.7；契约 §3.8（既有） |
| 不自动对外发布 | 计划 §1.10；契约 §3.8（既有） |

### 2.4 复盘

| 口径 | 出处 |
| --- | --- |
| 记录实际数据来源和期间，先对照当时决策包预期，再提出调整 | 计划 §1.10 |
| 净成交、退款、已结算/未结算、费用归属期必须说明；复购、转化率等缺分母或观察期不足时不计算 | 计划 §1.10 |
| **没有销售数据只能做准备复盘，不能伪称经营复盘完成** | 计划 §1.10 |
| 复盘经验候选只能进 `CompanyFact(status=PENDING)`，须人工确认才成为组织规则 | 计划 §1.7；契约 §3.9（既有） |
