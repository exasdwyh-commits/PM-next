# PM-next 三角色输出规范 - 结果导向版
时间: 2026-10-08
基于用户最新需求：领导层直观 / 产品研发专业严谨可信度第一工具丰富 / 销售营销卖点突出工具型

## 一、角色定义

### 👔 领导层 - 直观看的懂为主
**用户画像**：无技术/产品基础的老板、高管，需要10秒做决策
**核心需求**：一页看懂结论、风险、待决策，不看细节
**输出原则**：
- 一句话结论 24px 衬线加大
- 4张KPI卡片：已核实结论/风险/待补充/待决策
- 图表：环形图+条形图，颜色区分，不展示表格
- 去学术化：事实→✅已核实 / 推断→💡较可信 / 未知→❓待补充
- 极简决策卡：只显示推荐+最大风险
- 密度：摘要默认

**示例**：
```
💡 建议进入打样，配方可行，成本可控，风险是供应链单一
[✅6条已核实 67%可信] [⚠️2项风险] [❓2项待补充] [📝2项待决策]
```

### 🔬 产品经理/研发 - 专业严谨，可信度第一，工具流程丰富
**用户画像**：产品经理、研发、合规、成本专家，需要严谨数据和工具
**核心需求**：每条结论可追溯来源、核验状态、新鲜度，工具流程完整
**输出原则**：
- 完整表格：结论/类型/等级/来源/核验/新鲜度，数字右对齐
- 证据溯源：SourceCapture + 验证状态 + 内容指纹
- 工具丰富：
  - 成本计算器、渠道合规检查、证据缺口分析、机会分析
  - 工作项依赖图、运行回执、QA轨迹、决策包
- 流程：checklist (方法/通过线/周期/预算) + timeline (时间+阶段+交付物) + progress (进度条)
- 可信度第一：A级高可信/B级较可信/C级待加强/D级待核实，带统计
- 密度：完整默认

**示例**：
```
证据矩阵：
| 结论 | 类型 | 等级 | 来源 | 核验 | 新鲜度 |
| 80度留存率82% | FACT | A | 实验室报告 | 2人已核验 | 7天内 |
工具：[成本计算器] [合规检查] [缺口分析] [QA轨迹]
```

### 💼 销售营销 - 卖点突出，工具型，销售支撑
**用户画像**：销售、营销、渠道，需要卖点和工具去卖货
**核心需求**：卖点提炼、竞品对比、市场数据、一键生成销售工具
**输出原则**：
- 卖点提炼：从结论中提取高可信FACT，转为客户价值
  - 例如：留存率82% → “健康功效突出，抗氧化强”
- 竞品对比：突出优势，选中行高亮，带“推荐”标签
- 市场机会图表：增长趋势，带销售话术提示
- 工具箱：一键生成
  - 📽️ 销售PPT、📝 销售话术、⚔️ 竞品对比卡、💰 报价单、📊 市场数据图、🎯 客户案例
- 话术：可直接复制的销售话术，包含数据和利益点
- 密度：摘要+卖点，完整+工具

**示例**：
```
🔥 核心卖点：低糖多酚，80度留存82%，成本10.2元，竞品299元
💎 卖点卡：健康功效突出 | 客户价值：适合肠道健康人群
💼 工具：[生成销售PPT] [销售话术] [竞品话术]
💬 话术：“我们的产品实验室验证留存率82%，成本仅10.2元...”
```

## 二、全形态映射 (12种Block × 3角色)

| Block类型 | 领导层 | 产品研发 | 销售营销 |
|----------|--------|----------|----------|
| prose | 摘要段落 | 完整段落+来源标记 | 卖点提炼+客户价值 |
| keypoints | 图标+一句话 | 表格：结论/类型/等级/来源/核验 | 卖点卡片+客户价值 |
| table | 卡片式，3行 | 完整表格，数字右对齐，pick高亮 | 竞品对比，优势高亮 |
| chart | 迷你条形 | 完整条形+来源+单位 | 市场机会+销售话术提示 |
| checklist | 简化为进度 | 完整：假设/方法/通过线/周期/预算 | 销售准备清单 |
| timeline | 当前阶段高亮 | 完整时间线 | 上市时间线 |
| decision | 极简：推荐+风险 | 完整：推荐/反对/风险+置信度 | 销售决策+主推理由 |
| qa | 隐藏 | 完整轨迹：打回→修订→通过 | 隐藏 |
| callout | 风险/提示图标化 | 完整提示 | 销售提示 |
| unknown | 待补充数量 | 完整：问题+需要 | 隐藏或转销售机会 |
| evidence | 隐藏 | 完整溯源：标题/信任度/时间/URL/快照 | 市场数据+消费者洞察 |
| progress | 进度条 | 完整：进度+步骤+状态+耗时+增量文本 | 隐藏 |
| clarify | 行动卡：现在最重要 | 完整表单：问题/为什么/选项/记忆 | 简化为客户需求确认 |
