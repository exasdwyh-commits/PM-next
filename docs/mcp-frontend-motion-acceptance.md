# KX-26 前端动效验收（B 线收尾）

范围：KX-23 主叙事、KX-24 质感件（Notch / Terminal / Bento）、KX-25 页脚与侧栏状态区。
原则见 `docs/mcp-motion-principles.md`（动效只承载真实状态，不装饰）；组件见 `docs/mcp-kx-ui.md`。
过程脚本（不入库）：`scripts/_kx26-shot.mjs`、`scripts/_kx25-shot.mjs`；截图：`outputs/kx26/`、`outputs/kx25/`。

## 1. 方法

| 项 | 做法 |
|---|---|
| 驱动方式 | 临时预览页 `/kx23-preview` 用 7 个固定事件步（无契约 → 有契约 → 有计划 → 执行 → 提问 → 证伪 → 完成），由页面暴露 `window.__step(n)` 逐步推进；**不是定时器自动播放**，每一步都对得上一条真实事件 |
| 覆盖 | 7 步 × 3 宽度（1440 / 1024 / 390）× 深浅 × 降动画 = 84 张 + 12 条长任务记录 |
| 指标 | 每步统计帧间隔：> 50ms 的帧数、最长帧；页面 `longtask` 条目数；横向溢出 `scrollWidth - innerWidth`；控制台 error / pageerror |
| 结构化断言 | 每步读出故事轨 `aria-label`、当前站、动态岛文字、节拍条数、日志条数 |
| 录屏 | 浅色 1440 的一次完整推进（含动画），`outputs/kx26/*.webm` |
| 降动画 | `reducedMotion: "reduce"`，断言文字与结构不变（轨站位、动态岛文字、节拍、日志逐项一致） |

## 2. 结果

| 检查 | 结果 |
|---|---|
| > 50ms 的长帧 | **0**（最长帧 17ms，等于 60fps 的一帧） |
| longtask | **0** |
| 横向溢出 | **0**（1440 / 1024 / 390 均无） |
| 控制台报错 | **0** |
| 降动画 | 84 张截图 + report.json 中 12 条降动画记录的站点、动态岛文字、节拍、日志与开动画时**逐项一致**，信息未丢 |
| 与事件流对应 | `tests/mission-story.test.ts` 4 项断言（站点只由真实字段决定；停下 / 暂停 / 提问 / 取消的色调与文案；假设 / 证伪 / 收回逐条可见、模型调用不进日志；无事件时不编造） |

```

step6-light-1440  phase=执行  notch=K有个问题等你回答…              log=1  beats=2（推断 + 被推翻）
step7-light-1440  phase=交付  notch=K已完成，可以带走结果            log=0  beats=3（+ 已收回）
```

## 3. 逐件验收

| 件 | 动效 | 验收 |
|---|---|---|
| `StoryRail` | 当前站圆点长成带文字的 pill，已走过的连线变品牌色 | 7 步的 `aria-label` 依次为「第 1 / 5 步，理解需求」→「第 5 / 5 步，交付」；降动画下同样读到 |
| `Notch` | 文字换新时新文字升起；进行中有呼吸点，done / idle / warn 即停 | 呼吸点 `kx-live` 已登记循环白名单（仅表示「进行中」）；降动画无呼吸，文字完整 |
| `Terminal` | 最新一条日志升起；只渲染真实工具调用，模型调用不进 | step4 起出现 1 条；失败的调用标红 |
| `Beats` | 推断 / 被推翻 / 已收回新行升起 | step5 起 1 条，step6 起 2 条，step7 起 3 条 |
| `Bento` | hover 上浮 1px（`--m-tr-ui`） | Muse 空态示例任务：1440 / 1024 三块 88 + 92 + 92px 高，390 单列；最小 88px > 44px |
| `PublicFooter` | 无动效 | 登录页页脚在 3 宽度 × 深浅均可见；只有 K 标、说明、版本、年份，无空链接 |
| `SidebarStatus` | 无动效 | 侧栏底部：系统状态 + 用量 / 账户入口 + 版本；≤960px 撤掉链接（侧栏收窄后够不着），≤800px 随既有断点整块隐藏 |
