## 2. 启动方式

```bash
# 0) 环境配置：复制 .env.example 为 .env 并填入本机值（口令不在仓库中）
# 1) 数据库（本机 Postgres.app 17，端口 5433）
# 2) 安装与客户端生成
npm install && npm run prisma:generate
# 3) 建号（管理员操作，无公共注册）
npm run user:create -- --email a@b.test --name "张三" --password '...' --org-code HERMES_FOOD_DEV
# 4) 开发 / 生产
npm run dev            # http://localhost:3100，DEV_MOCK_AUTH=true 时保留免密快捷登录（仅开发）
npm run build && npm start
# 5) 测试（全部从环境变量取连接串，隔离校验不过即失败）
npm run test:db        # 事务与幂等
npm run test:acceptance && npm run test:r1 && npm run test:p1 && npm run test:r2 && npm run test:r3
npm run test:revision && npm run test:partial   # 版本一致性与局部修订
# HTTP 验收（先以生产模式起服务，连测试库）：
#   DEV_MOCK_AUTH=false DATABASE_URL="$TEST_DATABASE_URL" npx next start -p 3110
#   BASE_URL=http://127.0.0.1:3110 npm run test:http
# UI 证据（先起开发模式服务 3111）：
#   NODE_PATH=<含 playwright 的工程>/node_modules npm run test:ui
```
