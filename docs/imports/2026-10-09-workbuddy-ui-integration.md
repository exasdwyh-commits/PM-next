# Workbuddy 与 Kern UI/UX 整合（2026-10-09）

## 结论与范围

以当前 `feat/arena-workspace-port` 工作目录为基础，保留 Workbuddy 新增模块、接口与授权检查，补回已完成的 Muse、项目及原生成本工作区优化。核心 UI 可用性完成验收；未挂载的 rich 演示组件不作为真实业务能力交付。

## 界面与交互

- Muse：问候后显示一份当前工作简报；负责人、产品研发、销售经营视角按组织和账号保存，跨页面及刷新恢复。视角不改变权限或任务执行策略。
- 项目：复用 Workbuddy 的 OverviewRoleBased 入口，由真实 ProjectBrief 提供内容；统计已验收工作项、已核实证据、待审决策及前置依赖。移除固定的竞品价格、成本、留存率、自动调度和“证据已足够”判断。
- 每个摘要按钮跳转到真实工作区；项目恢复原生成本情景页签。
- 项目与产品成本：基础输入、销售履约、高级费率分区；四项结果指标；修改输入使旧结果失效；计算后将焦点移至结果。必须显式选择真实工作项才可保存，服务器重新计算，刷新后能重新载入。
- 报告阅读：保留摘要/完整模式、章节导航、来源跳转及可见键盘焦点。
- 390px 手机宽度：概览和成本页面无横向溢出，显示的输入控件至少 44px 高。

## 同时修复的集成问题

1. 新来源抓取与 computer-use 原型存在模拟成功路径。实验 API 及底层模块现明确返回 503 unavailable；研究集成在数据库操作前停止。没有模拟证据写入或额度扣除，现有真实研究/桌面任务流程继续保留。
2. Workbuddy cost-guard 未检查条件 UPDATE 影响行数。现额度仅在更新一行时放行；退款原子认领有效预约，重复/未知预约不会再释放额度。
3. 未发布的数据库迁移曾删除 supportSpan 后重建。改为 `ALTER TYPE JSONB USING to_jsonb`，保留原字符串内容和 NULL。当前开发库从 42 升到 43 个迁移；升级前后该表记录均为 0。另在隔离测试库使用真实 PostgreSQL 证明非空中文、多行、引号及 NULL 全部保留。
4. 测试库已应用过 Workbuddy 的旧版本迁移；在验证 JSONB 结构、旧校验值与已完成状态后，只对隔离测试库同步本地未发布迁移的校验值。开发库直接应用修正版。核对记录在 outputs 中。
5. 补回独立分支中已有的竞品原始意图判断、VALIDATION_EXECUTED 校准与持锁 Worker 存活判据测试，避免分支切换丢失修复。没有改变 Worker 的执行实现或扩大承诺。
