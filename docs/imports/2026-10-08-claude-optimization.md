## 结论

第二版不能整包覆盖：相比第一版缺少 111 个 src 文件，部分入口仍依赖被省略的文件；并会回退当前主线的竞品意图与 VALIDATE 评估修复。完整候选的静态检查产生 98 行诊断，涉及缺失导出、Schema 不匹配和不存在的字段。

本次将可用的交互思路改写为当前项目可运行的功能，复用现有认证、注意力引擎、成本引擎和结构化成果保存接口。

## 已接入

| 功能 | 实现与边界 |
| --- | --- |
| 负责人 / 产品研发 / 销售经营视角 | Muse 首页和项目概览可手动切换；按组织和账号保存本机偏好。项目摘要卡片随视角调整。视角不更改权限、专家路由或执行策略。 |
| 当前工作简报 | Muse 复用现有用户注意力记录，显示待处理事项和执行任务。当前摘要有数量上限，不作为全组织统计或每日新增数。读取失败明确提示，并保留成功读取的事项。 |
| 项目工作简报 | 从真实 workItems、当前诊断缺口、已核实证据和待审决策读取；只有 ACCEPTED 计入完成。没有记录时展示空状态。 |
| 前置依赖展示 | 概览可展开任务及依赖；未验收、缺失或格式异常的前置依赖不会算作满足。不推测负责人、日期、关键路径，也不自动推进任务。 |
| 项目成本情景 | 新增成本页签，复用原生材料、包装、制造、物流、渠道、税费计算器和产品情景接口。项目页和产品页明确选择真实工作项，服务器复算并落 Artifact，支持刷新后载入与情景对比。 |

成本入口当前采用人民币试算口径。项目页未加载产品版本的目标成本；产品页仍保留预算对比。未关联产品或未建工作项时可试算，不能保存。服务端保持既有产品读写权限，开发态身份切换沿用 identityHeaders。

## 本次运行时验证补齐的原生缺陷

- 原成本保存函数缺少项目关联，实际 API 返回 422。已从服务器查询的 WorkItem 推导 projectId、productId 和 inputRevision，补齐结构化成果信封，保留复算与权限校验。
- 原产品成本页把 Project id 当作 WorkItem id 提交。已改为显式选择「项目名 · 工作项名」，未选时不能保存；展示对应项目链接，查询采用确定排序。多项目（含无工作项项目）场景已实际验证。
