Kern · 动效原型 v0

主叙事 · 一个请求变成交付物

整个过程只有一个物体：输入框 → 思考胶囊 → 澄清卡 → 计划卡 → 执行进度 → 报告 → 表格 → 下载卡，然后首尾衔接回到输入框。每一章都能点时间轴直接跳到；中途点击、切换章节都可以随时打断。

提示：输入框阶段可以直接点发送按钮；下载卡可以点下载。

按钮与微交互 · 替换现有 Btn（60 处引用）

主按钮

按下缩放 0.96；hover 时光泽扫过一次，柔光跟随指针。只动 transform 和 opacity。

加载 → 成功

按钮收成圆形并转圈，完成后描出对勾，再展开回原样。结果以真实回执为准，不做假进度。

长按确认（受保护动作）

用于覆盖写入、删除、对外发送。按住 1.2 秒才会生效，中途松开就取消，防止手滑点错。

复制 / 分段切换

图标交叉淡入淡出；分段控件的指示条靠弹性曲线滑到选中项。
