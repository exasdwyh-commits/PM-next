# 报告模板（示例）

「产品立项分析报告」的 HTML 渲染模板，用于把报告产出接进统一版式。
**目录内全部数值为构造示例，不代表任何真实产品。**

## 文件

| 文件 | 粒度 | 说明 |
| --- | --- | --- |
| `report-template.example.html` | 决策层 | 单文件模板。12 区块、三态标注、A4 打印、零外部依赖。 |
| `report-full.example.html` | 执行层 | 同一产品的深度报告示例：规格 / 配方与 BOM / 工艺与中试 / 质量与稳定性 / 定价敏感性 / FMEA / 验证排期。 |

## 模板约束（设计时确立）

- **单文件**：CSS 内联，无外部 CSS / JS / 图表库依赖。
- **无交互 JS**：除打印按钮外不引入脚本，保证离线与打印可用。
- **A4 打印友好**：`@media print` 下分页不断块、背景色保留。
- **窄屏可用**：≤768px 时表格横向滚动，不挤压变形。
- **三态标注**：每条关键结论标记 `事实 / 推断 / UNKNOWN`，视觉可区分且不单独依赖颜色。
- **缺失不留白**：拿不到数据时显示「已知什么 + 缺什么 + 如何补齐」。

## 区块与产出角色

| 区块 | 产出角色 |
| --- | --- |
| 结论摘要 | 汇总 |
| 产品定位与机会 | 产品 |
| 成本与经济性 | 成本与 BOM |
| 销售机制与渠道 / 价格与分润体系 | 上市营销（+ 市场研究） |
| 营销策略 / 核心信息与话术边界 | 上市营销（+ 合规） |
| 风险评估 | 红队 |
| 合规边界（含产品类别与资质、平台准入） | 合规 |
| 验证计划与待决策 | 市场研究 + 汇总 |

## 与代码内报告格式的对照

代码内已定义 `PRODUCT_DEVELOPMENT_REPORT`（12 章，见
`src/modules/visual-intelligence/report-format.ts`）。

**两边对得上的 6 项**：产品定位、成本与经济性、销售机制与渠道、营销策略、风险评估、合规边界。

**模板独有**：结论摘要（独立首屏）、价格与分润体系、核心信息与话术边界、产品类别与资质要求、
平台准入、验证计划与待决策。

**代码格式独有**：机会与市场洞察、竞品格局与差异化、研发里程碑、增长指标与验证、
Token 与成本统计、附录：证据与未知。

差异方向：模板更贴近行业实报（多出资质 / 平台准入 / 话术边界 / 分润），代码格式更偏通用
立项决策（多出竞品 / 里程碑 / 增长指标 / 证据附录）。

## 两种粒度的分工

| | 决策层（简报） | 执行层（深度报告） |
| --- | --- | --- |
| 读者 | 决策者，一眼看懂、能直接开会 | 研发 / 成本 / 合规执行者 |
| 数据 | 结论 + 关键数字 + 三态标注 | 明细表（配方、工艺、稳定性、敏感性） |
| 长度 | 一屏到数页 | 十余页 |

两者不是两份独立产物，而是**同一份产品数据的不同投影**：简报取聚合值与结论，深度报告取明细行。
若把数值写进报告实例，会出现「报告显示 A、产品记录已是 B」的漂移；数值应由产品数据渲染。
